# Czechoslovakia Banking Analysis

## 📊 Project Overview
This project analyzes banking data to derive insights on customer behavior, transactions, and financial trends using SQL and Power BI.

## 🚀 Key Features
- SQL analysis on multi-million row dataset
- Complex joins and CTEs
- 40% query optimization
- Interactive Power BI dashboard
